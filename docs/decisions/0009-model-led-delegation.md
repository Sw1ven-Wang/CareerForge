# ADR 0009：模型自主委派与服务端权限边界

日期：2026-10-17。状态：已实施。补充 ADR 0007、0008。

## 从固定分派到按问题委派

新增 `agent-delegation-1.0` 协调任务及 `agent-delegation-task-1.0` 子任务，在原有队列、outbox、租约、阶段产物和收据上执行。用户在 `/agent` 展开“让 Agent 自主拆分调查任务”，选择技术目标、可读的固定版本候选、允许角色及总额度，输入问题。

父模型使用 `delegate_task` 自行选择是否需要委派、角色、目标、需求子集、单个候选和额度。角色包括需求分析、代码调查、证据复核、学习设计；代码角色可复用符号、相关实现与测试补读。学习设计返回建议，不提交正式计划。简单问题可直接结束为证据不足的说明，不强制创建任务。

这里的通用性指复用同一套协调和交接机制处理多种只读调查任务。可执行角色仍由服务端注册；不支持模型生成执行器、任意递归 Agent、任意 MCP、宿主目录访问或权限继承。

## 合同、最小范围与证据

根合同冻结需求版本及哈希、用户所选技术与候选、源码快照、来源版本、问题、允许角色、模型、调用上限与截止时间。子合同包含父 ID、类型化提议、来源指针、需求版本、单个源码快照哈希、只读工具白名单、上下文引用、调用与 token 上限、截止时间、输出 schema 和停止条件。

模型只能缩小授权范围。源码调查必须选择已授权候选；需求分析不获得代码工具。模型提议中的未知字段、越界角色/技术/候选和任意命令工具被拒绝，拒绝作为观察返回后续决策。每批仍为一层、至多两个子任务，子任务不能继续委派。

子模型只接收自身目标、所选需求及相关原文窗口，以及单仓库有界调查结果。父模型收到结构化交接：有原文引用的断言、未决问题、反证、实际用量、模型和系统停止原因；不拼接子任务完整对话。服务端验证摘录来自实际读取窗口，并在父任务发布和历史查看时重验来源、快照与哈希。

最终调查说明写为独立 `delegation` 产物。代码引用生成已有 CodeCitation，可点击跳转 IDE。原文定位校验、语义支持和运行事实分开；不自动入库、不修改正式学习计划、不确认人工验收或用户能力。

## 总预算、等待与恢复

用户总额度 3–10 次，包含父任务和全部子任务；父任务最多 2–4 次，子任务各 1–3 次，每次输出上限不高于根任务和配置，最高 8192。15 分钟截止从创建起算。

每次决策时同时展示当前账本和扣除本次决策、一次最终汇总后的可分配额度，并收紧 `delegate_task.call_limit` 的工具 schema。服务端仍独立校验总额度；工具 schema 或模型自报不能授予额度。子任务预留前强制保留一次父任务汇总可用额度。

创建、预留、outbox 同事务。父任务进入 `waiting_children` 让出 Worker，子任务完成结算后唤醒；可在后续决策轮按证据继续委派，但总数仍至多两个。所有付费决策、工具 schema、上下文与请求哈希保存，恢复复用原响应与原工具合同。未知请求不自动重试、不退已占用额度；供应商报告超限或存在未知请求时停止整个委派的后续调用。

父任务按根锁→子锁顺序取消、结算并阻止迟到写入。子任务不能单独发布业务结果；来源撤销、版本变化、过期或失去租约均阻止发布。取消不能保证收回已被供应商接收的请求。

## 帮助与执行权限

自主委派是学习辅助，同账号独立尝试期间禁止启动或继续。创建独立尝试也会拒绝尚在排队、运行或等待子任务的自主调查。来源、源码注释、模型摘要与问题均是不可信数据，不能改变工具权限。

此机制只读。命令确认、补丁审阅、计划采纳和人工验收仍走既有接口；子任务没有这些工具。没有新数据库或状态源，无新依赖或新迁移，沿用 `cf201017a002`。

## 验证边界

[本轮记录](../progress/REVIEW_D_DELEGATION_20261017.md) 区分必要离线工程验证和三次完全合成真实调用。真实验证发现并修复预算提示偏差；第三次确认模型提议能创建正确额度的子任务，随后取消。修复后未追加完整真实子任务执行与汇总验证。

供应商结构化格式未通过校验会停止，不宽松解析、不自动再次收费。没有独立保留集质量、并行收益、学习效果或成本改善结论。完整 skill 生命周期与全面事件协议统一仍属 D 包后续工作。
