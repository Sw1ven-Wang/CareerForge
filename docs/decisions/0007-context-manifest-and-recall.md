# ADR 0007：可回读的有界导师上下文

日期：2026-10-17；承接 review D 包中本轮指定的上下文管理、按需补读与证据回溯。

## 四区上下文与角色任务

新 Tutor 使用 agent-study-2.3 和 context-1.0。提取、调研、审核与计划继续使用 2.2；C 包和旧提交不迁移。新导师问题冻结 ContextTaskContract：角色、任务 ID、需求版本、计划/模块哈希、只读仓库范围、允许工具、帮助条件、调用与读取预算、停止条件。parent_run_id 目前为空；保留单个有界角色任务，不为本次功能新建子 Agent 调度系统。

ContextManifest 分四区：

- 固定区：服务定义的角色范围、权限、版本与允许辅助条件，不能压缩掉或从摘要中获得新权限。
- 工作区：当前模块、问题、当前待回答状态和剩余预算；没有细粒度步骤完成证据时保留 unknown。
- 证据区：短目录、来源 ID、版本、内容哈希、核验级别，以及本轮实际读取的代码。历史解释不是新的源码依据。
- 学习区：同模块兼容练习的既往提交与人工观察指针，保留帮助声明、未知和自验来源，不推断能力、误区或掌握分数。

目录至多包含同计划/模块最近 8 个历史回答、最近 5 次候选尝试中的已提交兼容记录和 3 个内置方法。数据库保留完整原始产物；目录摘要是确定性短摘录，不另调用摘要模型。目录不承诺涵盖全部历史；旧回答与旧提交仍由各自页面保留。

## 按需补读与方法资源

保留 search_code / read_code / related_code，增加 read_context_evidence 和 load_learning_skill。前者仅接受本轮目录中的 evidence_id，按 offset / limit 分页，每次最多 3500 字符，返回来源、版本、完整记录哈希、实际范围与 next_offset。没有任意文件、附件路径或跨账号查询工具。

历史引用可提供当前仍有效的代码候选，但必须再次 read_code 才能作为本轮源码依据。源码 read_code 继续支持显式行范围；结论只允许引用最终上下文实际保留的完整原文窗口。上下文不足时整体省略原文窗口并记录 ID，不把截断后的文字当完整引用。

三个内置学习方法为沿实现补证据、失败边界分析和围绕练习证据解释；版本/哈希随目录冻结。按需只读加载，不执行外部 SKILL、导入脚本、访问网络或授予工具权限。

每轮模型调用仍最多 1–3 次，最后一次留给回答；总计 7 次工具、最多 4 个已读代码片段，新增历史/方法补读合计最多 3 次且共用原工具总数。不会因加载方法或需要补读而增加预算。独立尝试期间仍由 C 包服务端暂停导师/IDE Agent。

## 预算、轨迹与回溯

上下文数据装配硬上限 28000 字符，原提示词 47000 字符上限不增加。按历史工具观察、已补读记录、学习摘要、历史摘要、较早代码窗口顺序省略；固定任务与证据目录超限则明确拒绝。所有省略和保留原文数进入 manifest。输入预算使用 UTF-8 字节的保守估计，不声称是目标模型 tokenizer 的精确结果；完整请求的提示词、工具与输出 schema 估计和供应商收据分别记录。

每次请求前保存 context:阶段产物，包括有界上下文、manifest、请求/提示词哈希与估计。长历史保留在 StudyArtifact，工具补读与长输出保留在 StageArtifact，数据库是状态真源。study.context 类型化事件只传引用、哈希与字符数。页面按用户展开显示清单、估计/真实用量、来源与分页回读，不触发模型调用。

新提示词使用确定性 JSON 键排序，避免 PostgreSQL JSONB 重排导致伪请求变化。恢复时对照完整请求哈希：一致且已有完整响应则复用；请求变化、仅有 attempted 标记或未知响应时停止自动收费重试。租约、取消和原有输入授权仍由运行内核控制。旧 2.2 导师任务不自动重跑，请用户发起新问题；历史回答可继续浏览。

## 失效与边界

补读、装配、发布、回溯和清理均重查归属、当前需求、审核项目与证据哈希。提交替换、人工确认/撤销变化、来源不可用时，冻结上下文不再被当作当前有效证据。清理授权识别 2.0–2.3，避免新导师错误进入旧 learning_path 校验。

历史模型解释仍未独立核验；原文位置有效不等于语义正确。人工观察仍是同账号自验，本人声明独立仍无法证明外部设备没有帮助；competence_verified 继续为 false。

本轮不增加模型调用、真实仓库执行、多 Agent 并行、向量库或额外桌面功能。轨迹恢复是工程验证，不是模型推理精确重放。没有独立保留集效果、成本改善或学习收益结论；相关实验需另行授权和真实数据。
