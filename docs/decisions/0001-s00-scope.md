# ADR 0001：S00 首条闭环及环境

日期：2026-10-12；状态：采纳。

用户选择 Agent 开发方向，允许只读使用 joblearn 项目材料，本轮仅离线模型验证。
采用本机 Python 3.12.14 + Docker Linux PostgreSQL/Redis；Worker 从 S02 起仅在 Linux 容器运行。
Windows 的 localhost 数据库连接发生长时间等待，127.0.0.1 在真实测试中通过，开发配置使用明确 IPv4 和 connect_timeout。

首条目标为：为 CareerForge 的岗位分析任务提供持久化状态、事件与断线后恢复展示。
岗位原文支持工作流状态追踪与归档；“采用 outbox/epoch”等是本项目的工程方案，不冒充 JD 原话。
个人材料只能说明现有服务与数据导入实现可读，没有持久化 Agent 执行的测试材料，判断为暂不确定。

参考仓库固定 commit 与依赖锁文件独立保存。研究 commit 的实现只能支持已读范围；已安装版本的兼容性由测试证明，不声称两者完全相同。
真实模型契约暂缓是用户明确选择，不将离线结果写成供应商连通或模型效果。
三份样例来自同一雇主，其中一份为社招：只作方向和机制比较，实习统计仅纳入两份实习 JD，不宣称跨雇主泛化。
