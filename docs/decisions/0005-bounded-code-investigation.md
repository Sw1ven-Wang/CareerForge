# ADR 0005：固定快照上的有界代码调查

日期：2026-10-17；承接 review 的 B 包，工作流版本 agent-study-2.2。

## 调查方式

保留 Extract / Discover / Review / Plan / Tutor 及现有运行、租约、阶段产物和费用收据。Review 读取固定 commit 的已下载归档或本人已导入快照，不执行仓库、安装依赖或读取任意本机目录。

CodeInvestigation 提供 list_tree、find_symbol、search_text、read_span、references_of、find_tests、finish_investigation。Python AST 构建符号入口；非 Python 与解析失败的文件仍可按字面正文查找，但不提供精确调用图。引用关系是同名静态候选。

先由确定性导航读取正文锚点、相关被调实现与测试。候选摘要不是已读原文，只有 read_span 取得原文。模型如有额外预算，可继续检索、指定目标内后部范围和补读，最终报告只能使用实际读取的连续唯一摘录。读取保留原始换行。

## 预算与停止

- 每候选默认仍为 1 次模型调用：确定性补读后生成报告。
- 显式选择 2–3 次时，前 1–2 次允许模型选择只读工具；最后一次留给报告。每轮最多 3 个工具。
- 每候选总计最多 12 次工具、6 次源码读取；每次最多 70 行 / 2600 字符；README 最多 2 份、每份 5000 字符。
- 索引至多 6000 个 Python 符号、20000 个静态调用名称。单次正文查询至多 256 个候选；每个工具最多返回 12 个目标，均报告截断。
- 收集批次预算为 1 次发现 + 候选上限 × 每候选审核上限，启动确认显示总数，不能由模型增加。
- 所需证据足够/不支持目标是模型的停止提议；没有新候选或新已读原文、工具/读取/模型预算达到上限由服务停止。模型停止提议不代表语义支持验证通过。

调查依赖原有归档 1000 文件 / 12 MB 限制与 47000 字符上下文限制，不放大上下文或自动续费。工具不接受任意文件路径读取；read_span 的 target_id 必须由当前快照的本次调查先发现。

## 证据和恢复

阶段产物保存归档指纹、已读范围和哈希、工具决定与最终报告。按候选隔离 stage key，重复运行重建确定性导航并复用已保存决定；未知付费结果不自动重试。新版本不拿 2.1 的旧窗口静默重放。

断言保存 claim_id、mechanism_id、statement、support_refs、counterevidence_refs、verification_kind、review_status 和适用边界。原文依据绑定 commit、路径、行号、文件哈希、摘录哈希，入库后关联代码 citation。多段读取同一物理引用位置去重，不把重叠窗口误报为两处引用。

引用位置有效、解释语义支持待核验、无运行观察继续分开。模型报告潜在反证且未解决，或没有有效实现依据时，强相关降为 uncertain，不入库。静态测试代码不是测试通过，模型解释不自动成为语义批准。未提供独立语义评阅或能力掌握结论。

C/D 包的学习成果整合、子任务委派、通用上下文服务和公平模型效果评测不在此次范围。
