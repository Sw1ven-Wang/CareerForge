## B. 1.5.1 当前真实验收边界（2026-11-02）

本轮始终只在 dot 云端工作空间执行。已安装实际 Python production/dev 依赖、Node24 和 Pi1.3.0 SDK；已通过实际 Tree-sitter JS/TS/TSX/Go 解析测试，以及实际 Pi SDK 会话/工具循环（推理仍是明确测试替身，真实付费模型调用为0）。

通过官方签名/哈希验证的 Debian 用户态包，在独立本地临时进程中验证 PostgreSQL17.11、pgvector0.8.0、Redis7.0.15/8.0.2 和 Celery：迁移、SQL、并发预算/锁、知识权限/证据失效、缓存 singleflight、Outbox 投递。测试进程使用专用回环端口/新库，结束后清理。**这些是 native 本地进程测试，不是 Docker 测试，也不是负载/持久性生产验收。**

实际官方 Docker CLI/Compose 配置解析已通过；官方 rootlesskit 启动在 `newuidmap` 缺失处退出1。工作空间同时存在 `NoNewPrivs=1`、能力边界为0、无 cgroup 委派，未尝试绕过隔离。`verify_docker.py` 明确报告 `blocked`，镜像构建、容器运行与 Docker 沙箱隔离均为 `not_run`。参见 `validation/current/docker-attempt/`。

仍未成立：真实模型/Embedding/Reranker 质量、真实 GitHub 研究效果、独立人工 Gold/教学收益、生产级高负载/故障恢复/磁盘持久性、Docker 内核与资源/进程/网络隔离、跨平台安装、原仓库完整兼容和原数据库迁移。新增测试数量不替代这些验收。

## C. 本次测试可以证明什么

能证明指定离线样本中的服务状态转换、权限/引用/预算约束、恢复、缓存撤销、策略晋升拒绝路径和 HTTP/CLI 行为。测试中的模型、搜索、向量、沙箱替身在代码中明确标为 synthetic，生产不允许它们发布知识。

测试数量不是需求覆盖率；代码行覆盖率不是模型正确率。验收报告保留上述缺口，不以大部分测试通过代替整个产品完成。
