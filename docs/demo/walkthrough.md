# V1 离线演示

访问本机 8080，登录 README 中的专用合成账号。

1. 岗位分析查看三份已保存 JD 的要求、出处与分母。
2. 学习计划查看 joblearn 静态材料、未知原因、完整目标条件与采纳版本。
3. 项目学习查看固定 commit、局部捕获范围、引用及学习单元。阅读完成只保存进度。
4. 自主构建选择“合成工程演示，不是 joblearn 实验”，打开“合成迁移任务”。
5. 打开提交 v1，观察 unknown 与返修记录；打开提交 v2，查看合成补交、原 unknown 提案与追加的分项自验记录。
6. 计划重新对齐和采纳后，已有任务仍保持原状态与版本。运行记录可追溯七次真实队列执行。

所有提交输出和自验步骤均明确标为 SYNTHETIC，没有实际执行命令或证明作者理解。此演示证明工程状态链，不能计入真实学习验收。
