# 源码导入边界修复

原版单文件 100,000 UTF-8 字节限制拒绝本次固定 Commit 的 OpenAI Agents SDK `tool.py`（116,811 字节）和 `run.py`（155,777 字节）。1.6.6 将统一单文件上限改为 1,000,000 字节，直接导入、GitHub 归档解包和 CLI 读取使用同一常量，仍保留 12,000,000 字节总量、1,000 个文件、单行和二进制/路径边界。

本次仅重新获取并验证了两仓四份文件，不是完整仓库下载。模型单次读取仍受原来的行数和字符预算约束；允许导入较大文件不等于模型已读全文件，也不等于运行成功。

7 项新增回归覆盖真实尺寸级别的导入、分页读取、归档解包与各项上限。完整来源获取回执、Git blob SHA 与逐行摘录核对另存证据包。
