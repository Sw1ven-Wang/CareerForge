## API 与一致性

- `POST /api/v1/studio/workspaces/{id}/learning-reports/{report_id}/practices`：body 为 `expected_revision`、`exercise_index`，需幂等键；返回 `practice_id` 和最新 `workspace`。首次建立增加工作区 revision，重复选择复用已有草稿。
- `PATCH /api/v1/studio/workspaces/{id}/practices/{practice_id}/note`：body 为 `expected_revision`、`note`（最多 4000 字符）；冲突返回 409。
- 现有 `StudioAgentInput` / 手动 `CommandInput` 增加可选 `practice_id`。学习模式不接受该 ID；编码模式须使用练习绑定的目标。后端校验工作区归属和说明原文，不信任客户端传来的练习内容或引用身份。
- 使用工作区现有 JSONB actions 保存草稿和产物关联，无数据库迁移。接口 OpenAPI 与前端类型同步更新。

创建、模型调用前、输出发布、补丁应用和命令执行前重新校验目标与引用。来源不可读或原说明变化时，读取工作区会隐藏练习内容和关联输出，新的模型请求及补丁应用被阻止。命令外部执行结束后再次检查，来源失效则不发布生成文件补丁。逻辑隐藏不代表已运行物理清理或删除用户自己的代码文件。
