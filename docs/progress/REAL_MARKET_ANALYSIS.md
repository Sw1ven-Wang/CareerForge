# 真实岗位要求分析接入

日期：2026-10-12。使用已有 gpt-6.1-sol、reasoning_effort=low 配置。

## 已实现

资料库选定固定正文版本 → 岗位要求分析 → 真实 Agent → 引用校验 → 保存分析报告。
页面默认真实模式，保留离线整理模式。每次最多 5 份 JD，每份完整可读正文最多 12,000 字符，最多一次调用、2048 输出 token；重点候选最多 4 条，不承诺覆盖全部要求。失败、进程中断均不会自动重试付费调用。

`POST /api/v1/market-research-runs` 新增 `analysis_mode: real_agent|offline`，省略保持旧版离线行为。版本化工作流 `market-agent-1.0` 冻结正文哈希、目标版本、模型配置及已有事实版本；按岗位保存阶段产物和调用回执。报告保存 Agent 候选、分类、AND/OR 条件、原文引用位置、未归一内容和用量。页面可以定位冻结正文中的原文。

引用必须在对应 section 中连续且唯一，字符范围须匹配规范正文；概念必须由引用明确支持，不能由模型自行扩大字典含义。候选保留 auto_extracted，不自动确认为正式需求。正式统计和后续规划依旧只使用人工确认事实。在资料库确认后，用离线整理重新生成报告即可进入学习计划。
