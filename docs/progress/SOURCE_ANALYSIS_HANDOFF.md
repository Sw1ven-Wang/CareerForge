# 资料库 → 岗位分析 → 学习计划

2026-10-12：暂停扩展招聘采集，保留现有入口供后续导入；本次补齐现有资料库到下一步的页面衔接。

1. 在资料库点击“下一步：岗位要求分析”，从当前岗位/来源分类范围选择 1–20 份可读 JD。不会自动全选或混入模拟资料；标题、分类与来源均可核对。
2. 进入分析页时，将每份所选资料的最新正文快照 ID 固定传入。来源详情也可点击“用此版本分析岗位要求”，明确使用当前查看的历史或最新版本。
3. 分析页只接受当前账号可读的岗位快照，显示版本预选结果。已撤销、不可读、不属于当前账号或超过数量限制的项不会带入；分析创建仍由既有后端再次校验。
4. 核对职业目标后，用户点击开始离线分析；未自动创建运行、调用模型或确认岗位要求。标准化要求未确认时，正式统计分母仍可能为零，沿用既有契约规则。
5. 打开保存的报告，点击“将本报告用于学习计划”。计划页通过接口读取该报告及其职业目标，预选准确报告，展开个人材料与对齐入口，并显示同目标的已有计划。
6. 选择个人材料后再生成对齐草案。原计划不自动变更或采纳；计划编辑、保存新草稿仍沿用已有流程。

验证：前端类型检查与构建通过；浏览器实际选择两份牛客真实 JD，分析页正确预选两份 v1 快照。使用已有保存报告验证计划页准确接收报告并展开材料区域。没有新建分析/规划运行，没有付费模型调用，没有全量测试。
