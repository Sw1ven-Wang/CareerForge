# 同页学习工作台与内置 IDE

日期：2026-10-13。入口 `/studio`，侧栏“学习工作台 · IDE”。

## 已实现

- 左侧显示已有学习计划、目标、交付物和阅读步骤，可在抽屉内继续编辑已有计划。
- 中间显示固定 commit 的开源参考代码；点击阅读步骤或绑定的定位，自动打开对应文件、滚动到引用并高亮行范围。每次读取最多 200 行，可翻页。
- 已有目标没有阅读单元时，可以选择已保存的参考项目版本、文件和行号，手动绑定目标；不凭目标名称猜测代码位置。
- 同页切换自己的 IDE：工作区、文件列表、文本代码编辑器、保存、Tab 缩进、Ctrl/Cmd+S、未保存修改保护、目录副本导入和 JSON 导出。
- 工作区是数据库内独立代码副本，不写回宿主 joblearn 或参考仓库。最多 100 个文本文件、2 MB，总体面向小型练习。目录导入跳过依赖目录、标准私密目录和非支持文本文件；用户仍需自行核对待导入内容。
- 右侧代码补丁 Agent 使用现有 gpt-6.1-sol low，用户点击发送才调用，每次最多一次、4096 输出 token（按当前配置，新任务生效），无自动重试。上下文包括当前目标版本、最多 3 个引用、最多 3 个已读文件及最近 4 条工作记录；当前 UI 发送当前文件和当前引用。整个上下文限制 24,000 字符。
- Agent 提交解释、代码补丁和命令建议，不自动写文件或执行。补丁显示修改前后全文，应用时核对原文件内容，防止覆盖后续修改；未读的已有文件不允许修改。
- 命令逐条确认，执行结果保存退出码、stdout、stderr；命令产生的文件变更再次作为待审阅补丁返回，不自动应用，不自动标记计划完成。

## 命令执行环境

使用 `compose.ide.yaml`，启动方式：

```powershell
docker compose -f compose.yaml -f compose.offline.yaml -f compose.ide.yaml --profile app up -d --no-build
```

API 与独立 `workspace-sandbox` 容器通过专用 Docker volume 邮箱通信，不暴露 Docker socket。执行容器无网络、无模型密钥、不挂载宿主项目，根文件系统只读，工作区为 tmpfs。命令子进程降为 uid/gid 65534，限 30 秒、256 MB、64 进程、1 CPU。每次任务完成后 PID 1 退出，容器重启清理临时工作区；邮箱串行锁防止并发串扰。运行器退出前先冻结并清理后代进程，再读取生成文件；拒绝 symlink 读取。

当前镜像提供 Python/uv；Node/npm 命令可以作为建议审阅，但当前镜像未安装其运行时，执行会返回 127。完整 Java、Node 构建、依赖下载、长时服务和交互式终端尚未支持，需要专门运行镜像与依赖策略。当前 IDE 为轻量文本编辑器，尚无完整语言服务器、调试器或 Git 工作树。

前端编译、相关 Python 静态检查通过。新增迁移 `e13c9b27d401` 已应用，服务已部署。浏览器实际展示计划与已保存参考代码，已创建空白“我的学习项目”工作区，并在该工作区为模拟 W1 目标绑定 `types.py:118–128` 的示例定位，页面高亮可见；这只是导航示例，不认定本人能力或完成目标。原始开源项目仅作为学习文本，CareerForge 继续使用显式 Python 工作流，不引入 LangGraph 运行依赖。
