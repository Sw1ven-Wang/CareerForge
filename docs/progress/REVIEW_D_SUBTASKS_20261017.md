后续已增加模型自主委派的通用只读角色，见 [自主委派记录](REVIEW_D_DELEGATION_20261017.md)。下文对应前一轮固定审核批次。承接 [D 包上下文记录](REVIEW_D_20261017.md)，设计见 [ADR 0008](../decisions/0008-bounded-review-subtasks.md)。

## 已完成

- 固定版本项目审核可显式创建一个父任务与最多两个子任务。合同冻结需求、候选、源码版本、只读工具、额度和截止时间；子任务持久化执行，父任务等待时让出 Worker，结算后由 outbox 唤醒汇总。
- 预留先于投递，每次请求从预留转为已用；终止只释放未用额度，未知请求保持占用，重复创建和结算幂等。根任务统一限制总额度和每次输出上限。
- 取消与截止向活跃子任务传播，过期 Worker 不能发布。子任务只暂存，父任务持有效租约重验输入和引用后才发布审核及可能的入库；需求版本变化会阻止汇总。
- `/agent` 新增“用子任务审核固定版本（最多两个）”折叠入口，运行详情显示父子关系与预算账本。旧自动发现流程维持原顺序执行。
- 新增迁移 `cf201017a002`，OpenAPI 与前端类型已同步。

## 必要离线验证

本轮共通过 18 项相关离线用例：13 项既有运行内核回归、5 项新增子任务集成用例。使用独立 PostgreSQL 数据库 `careerforge_d2_scope_20261017` 与本地 provider 替身，不执行用户项目命令。

新增用例覆盖两个子任务并发、父任务汇总与发布幂等、跨用户隔离、重复分派、超额预留和提高输出上限的拒绝、父任务取消前已有子任务完成、未知在途请求不退款及迟到产物拒绝、截止释放额度、需求变化阻止入库。初次验证修正了 fixture 缺少版本字段和子任务阶段错误沿用 2.2 的问题，失败项定点重跑通过；已通过用例没有反复本地全量运行。

隔离库迁移升级及 Alembic schema check 通过；Ruff 通过；与 Linux CI 一致的 strict mypy 检查通过（148 个源文件）；Vue/TypeScript 生产构建通过，保留既有 bundle 大小提示。没有为本轮新增远程评测工作流。

## 受限真实验证：仅合成材料

用户选择完全合成的需求和代码。手写一份模拟岗位、两条技术需求和两份极小 Python 代码快照，全部位于隔离库；未读取或外发真实资料库的岗位正文与项目源码。供应商为 `https://modelflare.dev/v1`，模型 `gpt-6.1-sol`，推理强度 `low`。

最多两次调用，每次最多 8192 输出 token；实际恰好两次，无重试、无额外模型汇总。第一个子任务返回后确认计量未超限才执行第二个。供应商报告：

| 子任务 | 输入 token | 输出 token | 审核结论 | 入库 |
| --- | ---: | ---: | --- | --- |
| 合成工具分发 | 3232 | 1206 | weak | 否 |
| 合成异步调用 | 3194 | 1311 | uncertain | 否 |

父任务最终 `succeeded`，已用额度 2，未结算预留 0。此状态表示父子执行与审核结果汇总完成；不表示项目强相关或学习目标通过验收。两个极小示例不足以证明目标覆盖，审核未将其纳入项目库。

真实验证顺序执行两个子任务，离线替身用例验证并发路径。没有据此宣称并行更快、模型调查有效或成本降低。调用收据和请求哈希保存在本地忽略目录，公开记录不包含密钥、用户资料或原始供应商响应。

## 边界与未完成

当前是审核业务的单层有界子任务，不是任意角色的模型自主递归委派；每批最多两个，且只使用已有固定源码快照。原有 Extract、Research、Plan、Tutor 不会自动变成父子任务。15 分钟截止是服务端回收和阶段检查，不是供应商在途请求的强制网络中断。

D 包仍有通用委派扩展、完整 skill 生命周期、事件协议全面统一、独立保留集与顺序/分角色/并发的质量成本对照未完成。上下文与工程故障用例不能替代这些评测。
