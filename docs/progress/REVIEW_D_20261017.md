## 必要离线验证

仅执行 3 个上下文装配单元用例、2 个新集成用例和 1 个既有需求→调研→审核→计划→导师集成回归，共 6 项。已通过的用例未重复进行本地全量测试；失败项修复后定点重跑。

覆盖固定区不可静默截断、整个代码窗口省略与来源指针保留、原数据不被装配修改、摘要不扩权和不推断能力、按需方法/历史补读、长记录后部分页、跨用户/目录隔离、帮助模式来源、人工撤销及输入撤销后的失效。

集成用例在独立 careerforge_d_scope_20261017 数据库中使用本地 provider 替身和合成命令回执；不运行参考项目或用户命令。恢复案例先保存三次替身响应，再在发布前模拟租约丢失，回收并恢复时 provider 禁止调用，仍完成发布且收据数不增加。另一案例预置 attempted 标记但无结果，运行失败并保持零供应商调用。

初次恢复验证暴露 PostgreSQL JSONB 键重排导致请求哈希变化的问题；新上下文改为确定性 JSON 序列化后恢复通过。用例的错误导入与两处全文/分页断言也已修正，不修改产品权限或预算来让用例通过。

Ruff、与 Linux CI 一致的 strict mypy（143 个源文件）、Vue/TypeScript 生产构建与 OpenAPI/TypeScript 合同同步。保留 Vite 原有 bundle 大小提示。GitHub Actions 继续执行已配置的检查，没有为本轮增加新的远程评测工作流。
