# 人工需求 → 开源实现学习，以及桌面本机 IDE

日期：2026-10-13。以用户最新方向为准：职业需求与开源项目是两类核心资料；技术资料也是需求输入。需求侧完全人工导入，Agent 分析已有正文并检索代码，不负责搜集岗位或技术文章。

## 产品入口

主导航只有学习工作台、需求资料、开源项目。计划、岗位统计、方向设置与运行记录收进“更多”。首页进入学习工作台；需求资料默认平铺，原分类整理功能可展开，保留历史数据。自动招聘采集组件退出页面；POST /collection/runs 返回 410 MANUAL_REQUIREMENTS_ONLY，历史记录仍可读。

SourceType 增加 technical_material，普通导入复用 Source / SourceSnapshot，无迁移。可选择 1–3 份固定正文快照，每份非空且不超过 6000 字符；长文需要先人工导入学习片段，后端不偷偷截断。进入工作台不会自动调用模型。没有选择需求或明确使用已有目标时，学习 Agent 按钮不可发起，避免把旧模拟计划作为默认需求。

## 对应链路

复用 learning-studio-research-1.0 显式工作流、词法/结构检索及 search_code / read_code / related_code 只读工具。支持 source_snapshot_ids，无需先创建学习计划。冻结原文、哈希、项目版本与预算；任务执行和历史读取继续检查所有来源是否可读。

LearningGuide 新增 requirement_links：需求快照 ID、连续唯一原文、已实际读取的代码 citation_id 和对应解释。后端验证需求原文区间与哈希、代码引用及原文，页面展示“需求 → 开源实现”。未匹配到实现保持依据不足；技术资料不冒充招聘事实或正式岗位统计。原文准确不代表解释语义已经人工认可。

模型调用仍由用户发送触发，最多 4 次，每次按当前配置 4096 输出 token。学习模式不发送 IDE 文件、不写本机代码、不自动修改计划。未附已有目标的迁移建议直接带入编码助手输入，不伪造正式目标或验收任务。

## 本机 IDE

原生选目录后建立当前会话的目录句柄与独立工作区关联，后端不接收绝对目录，也不挂载个人项目。Rust 受限读写模块固定所选根目录、相对路径、文件类型和大小；拒绝私密路径、设备路径、symlink/junction/hardlink。Windows 持有目录句柄防移动与替换，读写文件拒绝其他写入与删除共享。原文/原始字节哈希必须匹配才能保存或应用补丁。

直接编辑只在本机保存，不自动复制到模型上下文。明确选择文件后，PUT /studio/workspaces/{id}/snapshot 原子替换后端输入快照，校验归属、版本、幂等和运行中状态；Agent 最多 3 个文件，沙箱/成果快照最多 100 个、2 MB。只把选中文件的规范化 LF 文本同步，原文件保留 BOM/CRLF。

补丁必须完整审阅并原生确认。检查整组旧版本后保存原始字节备份，再写入；不通过 Agent 删除本机文件。多文件不承诺跨文件崩溃原子性，失败尝试恢复，保留备份清单。后端记录同步失败时显示明确待同步状态，重试不再次写入已应用文件。

Tauri 新增能力仅授予 workspace 窗口 http://127.0.0.1:8080/studio 页面；不授予其他网页、Shell、通用 filesystem 或任意根路径命令。原生选择器与目录 token 必须先建立授权；退出会话清除绑定。只读 capabilities 探测可辨别旧桌面程序。

命令执行仍使用原有明确 RUN 确认及 Docker 无网络沙箱，只传所选快照，不执行本机目录或宿主命令。沙箱结果仍以补丁形式审阅后写入本机。未触碰原始 joblearn 或其他个人项目文件。

## 必要验证

仅执行 1 个离线集成场景及 2 个 Windows 临时夹具用例。集成场景覆盖人工技术正文、无计划的 Agent 工具检索、需求与代码双引用、虚构需求拒绝、快照同步/版本/幂等/越权、采集停用、来源撤销隐藏报告。首次失败为测试将服务端补齐的展示字段重新当严格模型输入；修正夹具后复验通过，未扩大测试。

两个 Windows 原生用例实际验证保存 BOM/CRLF、备份、整组新建/修改、旧版本冲突、重放，以及越界/私密路径与硬链接拒绝，均通过。无真实模型调用、无练习命令执行、无全量回归。后续只做必要静态检查、编译和部署入口确认。
