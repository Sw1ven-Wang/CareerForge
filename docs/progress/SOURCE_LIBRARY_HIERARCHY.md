# 岗位资料三级浏览与手动编辑

来源页为：岗位分类 → 来源分类 → 具体岗位与资料。

- 一级：添加岗位分类、编辑分类名称。
- 二级：添加来源分类、编辑名称、调整所属岗位分类。
- 三级：添加岗位（正文、附件或链接线索），编辑名称、来源链接、类型和所属来源分类；详情中的正文编辑保存新快照。
- 分类是持久化目录，允许空分类。改名或移动目录沿用稳定 ID，下属资料随目录展示，不改写历史正文、报告或计划。
- 新岗位继承当前层级的分类，导入表单仍可指定其他分类。旧资料首次进入页面时按已有标签或标题/域名初始化目录；之后以目录 ID 为准。
- 分类和岗位信息编辑支持所属账号校验、幂等键、版本冲突保护和同级重名提示。目录组织与冻结的标准化证据分开保存。
