# 岗位资料三级浏览

来源页改为：岗位分类 → 来源分类 → 具体岗位与资料。各级展示当前账号的资料数量，面包屑支持返回上级；详情、版本、岗位标准化与真实 Agent 入口继续沿用。

岗位分类和来源分类可在正文/附件导入以及快照修订时指定，支持自定义名称，存入快照元数据，无数据库迁移。未指定时按标题规则与链接域名显示分类；无法判断岗位方向时显示“未分类岗位”。链接线索暂按标题和域名分类，补充正文后可指定分类。

列表加载所有分页后分组，资料类型筛选覆盖三级目录。历史正文、报告及计划未做批量修改。
