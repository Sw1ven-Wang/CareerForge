公开 GitHub 仓库 + 完整 40 位 commit → 下载固定版本归档 → 筛选源码与文档 → 不可变快照和逐文件哈希 → 持久化结构 / 全文索引 → 预览真实片段 → 关联已有学习目标 → 学习工作台定位与高亮。

## 索引与检索

- Python 解析函数、异步函数、类、嵌套定义、docstring 与行范围；类头部和文件窗口保留结构上下文。
- 多语言源码、README 与文档先采用带路径的文本窗口索引；不声称已解析 Java、TypeScript 等语言的语法关系。
- PostgreSQL `simple` 全文索引和 GIN，结合路径、符号与原文命中排序。精确函数名优先；每轮最多 200 个候选、返回最多 50 个片段。
- 中文学习主题采用公开的显式别名表，例如“工具调用”扩展为 tool / dispatch / execute，可编辑项目名称、学习说明与主题标签。
- 保存的 Python 调用名称可导航至同名定义候选；包含关系与引用候选明确区分。候选可能有歧义，不证明运行时调用关系。
- 每次返回代码或创建引用都核对快照文本和哈希；撤销仓库后索引与引用不可继续读取。
- 引用绑定 commit、文件路径、行范围和内容哈希；现有 IDE Agent 可把打开的知识库引用作为参考上下文。没有引入额外模型调用。

当前 `retrieval_mode=lexical_structure`、`semantic_enabled=false`。这不是向量检索、BM25、模型重排序或完整 GraphRAG。Agent 自主多轮检索已由第二阶段提供，见 [知识库学习 Agent](KNOWLEDGE_AGENT_LEARNING.md)。没有添加 LangGraph 依赖。

## 导入边界

固定下载主机 `codeload.github.com`，只接受规范公开 GitHub 仓库地址及完整 commit，不跟随重定向，不发送模型密钥。下载上限 20 MB / 35 秒，归档最多 20,000 项 / 100 MB 声明解压量。不解压到宿主目录、不执行仓库代码。

筛选后最多 1000 个 UTF-8 文本文件 / 12 MB，单文件 100 KB，单行 25 KB；跳过标准私密目录、依赖与构建目录、symlink、二进制、空文件和超限内容。具体跳过数随快照保存，页面展示部分覆盖标记。此过滤不等于通用秘密扫描，手动导入仍需核对待导入内容。

不改动原始 joblearn，不安装导入仓库依赖。知识库只读导入与 IDE 命令确认策略保持独立。
