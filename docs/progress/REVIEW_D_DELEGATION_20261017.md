## 完全合成真实验证

只使用脚本手写的一份岗位、一个技术目标和一份极小 Python 工具分发代码，使用隔离账号/库。未读取或外发真实岗位、agentmesh、AgenticGoKit 或其他资料库材料。模型为已配置 `gpt-6.1-sol` / `low`，供应商 `https://modelflare.dev/v1`。

累计上限 3 次，每次最多 8192 输出 token；实际恰好 3 次，无付费重试：

| 调用 | 用途 | 输入 token | 输出 token | 结果 |
| --- | --- | ---: | ---: | --- |
| 1 | 初始自主委派 | 2344 | 384 | 模型申请子任务 2 次；会挤占最终汇总额度，服务端拒绝，未创建子任务 |
| 2 | 无子任务的汇总 | 2387 | 635 | 返回内容未通过 JSON 解析，运行停止，没有发布报告 |
| 3 | 修复后的委派提议核对 | 2483 | 245 | 模型申请代码调查角色、1 次额度，成功创建子任务并进入 waiting_children |

初始提示展示的是调用前余额，没有明确扣除当前决策费用。已修复为展示扣除本次决策及一次最终汇总后的可分配额度，并将其写入工具 schema；服务端拒绝规则保留。决策/最终阶段的提示也已区分，最终要求合法 JSON，不放宽解析或引用校验。

第三次仅验证提议与调度，不执行子任务、不再请求模型汇总；随后取消父任务及待执行子任务，预留归零。该探针的本地硬守卫防止第四次供应商请求。不能把此结果写成修复后的完整真实编码/调查闭环已经通过；最终真实子任务执行和结构化汇总尚未重验，离线完整路径已通过。

没有运行用户项目命令。请求哈希、计量与运行记录只保存在 Git 忽略目录。隔离库在保存必要计量后清理。
