项目位置与使用说明

首次进入桌面版需要登录；之后登录状态保存在桌面应用自己的 WebView 中。可从窗口菜单随时返回“服务状态”。

关闭桌面窗口后后台服务继续运行，避免打断 Agent 任务。启动服务不会调用模型、执行练习命令、下载镜像或删除数据。

Worker 与 Dispatcher 的“运行中”表示容器进程运行；模型请求、工具与任务结果请在工作台运行记录中查看。
